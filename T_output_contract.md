# T — Contrat de sortie (T-min)

Le verifier produit un verdict JSON déterministe contenant :

Champs dans l’ordre strict :
1. status
2. evidence (optionnel)
3. outcome (optionnel)
4. pointers (optionnel)
5. mode ("offline" si applicable)

Aucun champ implicite ou calculé n’est autorisé.
L’ordre des champs est normatif.
